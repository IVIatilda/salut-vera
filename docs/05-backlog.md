# Backlog Vera

Дата актуализации: 20 октября 2026

## Правила

- `Сейчас` — задачи текущего этапа, необходимые для устойчивого пользовательского сценария.
- `Далее` — следующий крупный блок после стабилизации текущего.
- `Позже` — важные функции, зависящие от еще не реализованных источников данных.
- Новая задача получает стабильный идентификатор по модулю.
- Backlog описывает результат для пользователя, а не только изменение файла или компонента.
