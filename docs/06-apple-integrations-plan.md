# План интеграций с приложениями Apple

Статус: отложено до появления устойчивой облачной синхронизации и мобильного клиента.  
Дата решения: 17 октября 2026

## Границы

- PWA остается основным интерфейсом Vera.
- HealthKit недоступен веб-приложению и не позволяет читать данные на macOS. Для
  тренировок потребуется нативный компаньон на iPhone или iPad и явные разрешения
  пользователя на каждый тип данных.
- Apple Books не предоставляет публичный API для чтения пользовательского прогресса,
  текущей страницы или времени чтения. Неофициальная автоматизация macOS не является
  надежным источником для продукта.
- Calendar и Reminders можно рассматривать после появления нативного моста через
  EventKit.
- Shortcuts — предпочтительный первый этап: пользователь явно передает Vera минуты,
  количество или факт выполнения.

## Целевая модель

Внешние данные не изменяют `HabitLog` напрямую. Сначала сохраняется исходное событие:

- `IntegrationConnection`: поставщик, разрешения, состояние и время последней синхронизации;
- `ExternalActivityEvent`: поставщик, внешний идентификатор, тип, период, значение,
  единица и устройство-источник;
- `HabitAutomationRule`: привычка, тип события, условие, способ агрегации и период.

Пример правила: «отметить привычку Спорт, когда суммарная продолжительность тренировок
HealthKit за день достигла 30 минут».

События должны быть идемпотентными, хранить источник и допускать повторный расчет после
изменения правила. Автоматическую отметку пользователь может проверить и исправить.

## Порядок реализации

1. Стабилизировать журнал привычек, идентификатор пользователя и облачную синхронизацию.
2. Добавить модель внешних событий без привязки к конкретному поставщику.
3. Реализовать действия Shortcuts.
4. Создать минимальный нативный компаньон и подключить HealthKit.
5. После проверки разрешений, дублей и часовых поясов добавить правила автоматизации.
6. Отдельно оценить EventKit для Calendar и Reminders.

Для чтения до появления официального API использовать таймер Vera, ручную запись
минут/страниц и Shortcuts.
